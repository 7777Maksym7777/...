# Практична робота №3 — FocusFlow

**Тема:** Проєктування складних макетів за допомогою CSS Grid, інтеграція мультимедіа та CSS-анімацій.

## Обраний варіант
Варіант 3 — промо-сторінка SaaS-продукту. Концепція FocusFlow — сервіс для фокусу, планування та балансу.

## Як запустити
1. Завантажте ZIP-архів і розпакуйте його.
2. Відкрийте `index.html` у браузері.
3. Для публікації створіть GitHub-репозиторій, завантажте `index.html`, `styles.css` і цей README.
4. У репозиторії відкрийте **Settings → Pages**, у полі **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`, натисніть **Save**.
5. Через деякий час GitHub Pages покаже публічне посилання на сайт.

## Виконані вимоги
- CSS Grid: сітки шапки, головного екрана, карток функцій, відеоблоку та тарифів.
- Мультимедіа: адаптивне зображення з `srcset`, `sizes` і `loading="lazy"`; відео з `controls`, двома `source` та `poster`.
- SVG: вбудований SVG-логотип та SVG-іконки.
- Анімації: `transition` для кнопок і карток; `@keyframes` для появи, плавання та пульсації.
- Семантика: `header`, `nav`, `main`, `section`, `article`, `footer`, заголовки, `alt`, `aria-label`.
- Адаптивність: медіазапити для планшетів і смартфонів; підтримка `prefers-reduced-motion`.

## Пояснення для захисту
**CSS Grid** — двовимірна система розміщення елементів. `grid-template-columns` задає стовпці, `grid-template-rows` — рядки, а `gap` — проміжки між комірками. Наприклад, `grid-template-columns: 1fr 1fr` створює два стовпці однакової ширини.

**Transition** плавно змінює властивість під час переходу між станами, наприклад при наведенні курсора (`:hover`). **Animation** запускає послідовність кадрів, описану в `@keyframes`, і може працювати автоматично без взаємодії користувача.
